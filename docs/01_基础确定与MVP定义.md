## 1. 目标人群重新定义（修正原 PRD 矛盾）

### 1.1 问题
原 PRD 写"50–65 岁 = 70后/80后"。按 2026 年实际年龄：70后为 47–56 岁，80后为 37–46 岁。"50–65 岁"其实对应 60后/70后，与"70/80后"自相矛盾。

### 1.2 修正后的定位
以**世代**为锚点，年龄区间收窄为 **45–55 岁的 70后/80后**：

- 他们**尚未退休**，但已进入"下半场规划期"——提前物色钓点/徒步线路/旅居小城，为退休生活做准备，同时利用现有假期"抢先享受"。
- 关键词从"退休养老"改为 **"半退 / 慢生活 / 下半场"**。

> 建议：产品对外仍可叫"退休生活 APP"（品牌资产、SEO 友好），但**内部人群模型与文案调性统一按"45–55 岁、迈向退休的 70/80 后"来做**，避免做成"老年 APP"。

### 1.3 用户画像（精修版）

| 维度 | 描述 |
|---|---|
| 年龄/世代 | 45–55 岁，70后/80后 |
| 生活状态 | 在职晚期 / 提前退休 / 自由职业 / 子女已独立，时间与积蓄逐步宽裕 |
| 数字能力 | 智能手机熟练，会用微信/短视频/网购，但反感复杂任务与花哨交互 |
| 心态 | 拒绝"躺平养老"，追求品质、真实、同频社交；有审美、有消费力、怕被"套路" |
| 核心需求 | ① 找到真实靠谱的玩乐/旅居情报 ② 找到同龄同好结伴 ③ 避坑、省心、精致规划下半场 |
| 核心痛点 | 全网攻略年轻化/滤镜化、广告泛滥、踩坑率高、缺同龄人实测、找不到同频玩伴 |

### 1.4 反向定义（我们**不**是谁）
- 不是红松/兴趣岛式"网课+养生+才艺"的老年 APP。
- 不是小红书/抖音式"年轻人滤镜+广告+种草套路"。
- 不是单一爱好垂直 APP（只有钓鱼 or 只有登山）。

## 2. 定位与 Slogan 确定

### 2.1 一句话定位
> **面向 45–55 岁 70/80 后的"下半场"户外慢生活情报与同好社区**——同龄人实测、无套路、结构化干货。

### 2.2 Slogan（保留原句 + 备选）
- 主用（沿用原稿）：**退休不褪色，玩好后半生**
- 备选（更贴合"半退"人群，供 A/B）：
  - 下半场，才是自己的场
  - 提前规划，把退休过成向往的样子
  - 同龄人实测，玩得真、玩得省、玩得对

### 2.3 品牌调性关键词
真实 · 靠谱 · 无套路 · 高级简约 · 慢节奏 · 同频。（贯穿 UI、文案、内容审核标准。）

## 3. MVP 范围定义（大幅收窄）

原 PRD 的 MVP 包含 5 垂类 + 全地域 + 积分 + 段位 + AI 审核 + 同城，对"1 人 + AI"而言范围过大、且冷启动无法覆盖。收窄如下。

### 3.1 首发垂类（建议：钓鱼 + 登山徒步）
选择理由：
- **钓鱼**：社群黏性最强、发帖频率高、内容天然结构化（钓点/水质/鱼种/时段/停车/收费），最易沉淀"干货壁垒"，也最容易找到愿意分享的种子达人。
- **登山徒步**：受众面更广、四季可玩、与"中老年适配难度"强相关，和钓鱼人群高度重叠（同一批爱户外的中年人）。
- 其余 3 类（旅游旅居 / 高尔夫 / 乡居慢享）**移入第二、三阶段**，在首发城市跑通后按数据加。

> 可选替代：若你的资源/人脉集中在某一类，也可**只做 1 个垂类**首发（更快跑通）。见第 6 节。

### 3.2 首发城市（单城集中）
冷启动的铁律是"一座城市打透"。选城标准（按权重）：
1. 你**本人/团队有本地资源**（能约到种子达人、能自采内容）——权重最高；
2. 70/80 后中产人口基数大、户外/钓鱼文化活跃；
3. 周边 2 小时车程内钓点/山线资源丰富。

> 建议候选：成都、杭州、武汉、南京一类"新中产 + 户外氛围浓"的城市；**最终以"你有没有本地资源"为准**。请在第 6 节确认。

### 3.3 MVP 功能清单（做什么）

| 模块 | MVP 纳入 | 说明 |
|---|---|---|
| 情报社区 | ✅ 发帖 + 结构化模板 + 浏览 + 收藏 | 仅首发 2 垂类，含"干货帖"结构化字段 |
| 内容排序 | ✅ 可信度基础版 | 先用**简化规则**（见 3.5），不上复杂算法 |
| 同城 | ✅ 单城默认 + 兴趣小组浏览 | 首发城市写死，群组可只做"浏览/进群" |
| 适老化 | ✅ 大字模式 + 高对比度 | 语音发帖/语音搜索**后置** |
| 积分 | ⚠️ 极简版 | 只做"发优质帖 +X 分、点赞 +1 分"，段位/兑换后置 |
| 内容审核 | ✅ 人工为主 + AI 辅助 | MVP 阶段量小，**以人工审核为主**（合规要求，见第三阶段） |
| 个人中心 | ✅ 基础主页 + 我的帖子/收藏 | 段位称号、达人认证**后置** |

### 3.4 明确 Out of Scope（MVP **不做**，避免范围蔓延）
- 结伴发布、线下活动、AI 反作弊、AI 智能推荐、8 级双风格段位、垂直称号、积分兑换、达人认证、轻会员、严选服务/团购、语音交互、离线保存。
- 以上进入第二/第三阶段，**且必须有数据支撑再上**。

### 3.5 MVP 版内容排序（简化规则）
不做复杂算法，先用可解释规则：

```
排序分 = 干货基础分(满足几项结构化标准 ×10)
        + 有效互动分(收藏×2 + 同城点赞×1，有上限)
        - 风险分(被有效举报/无图水帖)
新帖有 48 小时曝光加权，避免"沉底"。
```

干货帖判定沿用原 PRD：实拍图≥3、精准定位、含关键场景参数、原创实测——**满足 3 项及以上**记为干货。

## 4. 冷启动策略（原 PRD 完全缺失 · 最高风险项）

本产品价值 100% 依赖"真实 UGC 情报"，但 0 用户时没有内容、没有内容就没用户。必须主动破解这个鸡生蛋问题。分三步走：

### 阶段 A：种子内容自建（上线前 4–6 周，目标 100–150 条干货）
- 由你 + AI 亲自产出首批内容：实地/半实地采集首发城市的钓点、山线，套用结构化模板，AI 负责排版规整、补参数、去水词。
- 目标：**每个热门场景先有 3–5 条可用干货**，让第一个真实用户进来就"有东西可看"。

### 阶段 B：种子达人招募（上线前后，目标 10–20 位）
- 定向找首发城市的钓鱼/徒步 KOC（钓具店老板、户外群群主、本地领队）。
- 给"创始达人"权益：专属徽章、首页推荐位、内容署名、（后期）活动优先权——**用荣誉与曝光换内容，不用现金**（符合"无套路"调性且省成本）。
- 达人负责持续供给 + 带来第一批真实用户。

### 阶段 C：本地社群导流 + 线下渗透（上线后）
- 从现有微信钓鱼群/户外群定向拉人（先内容后拉人，避免硬广被踢）。
- 一场小型本地"野钓/徒步"线下活动即可带来一波高质量种子用户与内容素材。

### 供需平衡原则
初期**内容供给 > 用户增长**：宁可用户慢一点，也要保证进来的人"看得到干货"。避免拉来一批用户却发现是空社区而流失。

### 冷启动成功门槛（进入下一步的条件）
- 首发城市 2 垂类累计 **≥300 条干货帖**；
- **≥30 位真实活跃发帖者**（非运营自建）；
- 次周留存见第 5 节目标。

## 5. 成功指标（KPI）与北极星指标（原 PRD 缺失）

### 5.1 北极星指标（North Star Metric）
> **每周产生/消费"有效干货情报"的活跃用户数（WAU-干货）**
> 定义：一周内 发布≥1 条干货帖 或 对干货帖产生有效互动（收藏/实测评论）的用户。
> 它同时衡量"内容供给"和"内容消费"两侧，最贴合产品本质。

### 5.2 MVP 阶段目标（内测闭环判定）

| 指标 | 目标（MVP 结束时） | 意义 |
|---|---|---|
| 干货帖总量（首城 2 垂类） | ≥ 300 条 | 内容壁垒是否成立 |
| 真实活跃发帖者 | ≥ 30 人 | 供给侧是否自转 |
| 次周留存（W1 retention） | ≥ 25% | 中年高质量人群留存基准线 |
| 次月留存（M1 retention） | ≥ 15% | 是否形成习惯 |
| 干货帖占比（干货/总帖） | ≥ 60% | 社区纯净度、审核有效性 |
| 人均周浏览干货数 | ≥ 5 | 内容是否被真正消费 |

> 判定：以上多数达标 = 冷启动成功、可进入第二阶段（结伴/社群/推荐）；否则先修内容与留存，不急着加功能。

### 5.3 关键漏斗（要埋点）
`曝光/拉新 → 注册 → 首次浏览干货 → 首次收藏/互动 → 首次发帖 → 次周回访`
每一环转化率都要能看到，尤其"注册→首次发帖"（供给侧激活）。

### 5.4 反指标（护栏）
- 水帖/广告举报率、被下架内容占比（越低越好）；
- 用户投诉"找不到同龄人/内容假"的比例；
- 若为拉增长牺牲内容质量导致干货占比下降，视为**警报**。

## 7. 下一步（第二阶段预告）
基础锁定后，第二阶段将补齐**开发可落地**的部分：
- 核心用户流程（注册→浏览→发干货→互动）
