## 3. 코드 / 배포
- **GitHub**: https://github.com/kcbcgz1-sudo/zhixian (Public, 기본 브랜치 main)
- **로컬**: `D:\app` (git). mobile/ · server/ · docs/
- **배포**: 로컬 `git push` → 서버 `git pull` 후 재빌드/재시작
  ```
  cd ~/zhixian && git pull
  cd server && npm install && npx prisma db push && npm run build && pm2 restart zhixian-api
  ```

- 클로드가 push하면 서버가 알아서 업데이트됨(사용자 조작 불필요)
- 서버 접속키/호스트는 GitHub 저장소 Secrets(SSH_HOST/USER/KEY)에 등록됨
