## 已锁定决策
- 产品名：**知闲**（对外可并用"退休生活"副标）
- 人群：70/80 后，45–55 岁，准退休/半退世代
- 首发垂类：钓鱼 + 登山徒步
- 首发城市：广州
- 资源：1 人 + AI + 可外包
- 形态：**独立 App**（非微信小程序），长期慢养
- 技术栈：**Expo (React Native) + TypeScript**（前端）/ **NestJS + PostgreSQL + 对象存储**（后端）/ 境内云托管 / 安卓优先

## 로컬 실행 (mobile) — Windows
```
cd D:\app\mobile
npm install
npx expo start        # 안드로이드폰에 Expo Go 앱 설치 후 QR 스캔
```
