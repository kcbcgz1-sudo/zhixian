## 1. 合规与法务（国内 UGC 社交 App · 高优先，先想清再开发）

> ⚠️ 这一节涉及资质与法律，**务必在正式上线前咨询专业律师/代理机构确认最新政策**。以下为立项须知与准备清单，非法律意见。

### 1.1 上线资质（App 想上架/合规运营的前置）
| 事项 | 说明 | MVP 阶段做法 |
|---|---|---|
| 主体 | 需有公司主体（个体户/有限公司），个人主体几乎无法办社交类资质 | **先注册公司主体** |
| ICP 备案 | 有服务端/域名即需备案 | 服务器落地国内即办 |
| 网络安全等级保护(等保) | 用户数据到一定规模需等保二级 | MVP 先合规存储，规模上来再办 |
| 应用商店上架 | 各安卓商店/苹果需提供资质、隐私合规材料 | 内测可用 TestFlight / 内测分发，正式上架再备齐 |
| 含"社交/直播/资讯"属性可能涉及的许可 | 视功能而定（如涉及资讯发布、音视频） | MVP 只做图文 UGC，**先不做直播/新闻资讯**，降低资质门槛 |

> 建议：MVP 内测阶段用**小范围邀请制**跑通，不公开上架，可显著降低合规压力；同时并行推进公司主体与备案。

### 1.2 个人信息保护（PIPL / 个保法）
- **实名认证**：社交 App 需落实真实身份信息（后台实名、前台可用昵称）。MVP 可**手机号实名**起步（手机号已实名），人脸/身份证实名放规模化后。
- **隐私政策 + 用户协议**：上线必备，明确收集哪些信息、用途、存储、第三方共享（微信登录、地图 SDK 等都要写）。
- **最小必要原则**：只收业务必需信息；定位、通讯录等敏感权限要**用时申请 + 说明理由**。
- **数据存储**：用户数据存境内；敏感信息加密；提供账号注销与数据删除入口（法定要求）。
- **未成年人**：产品面向 45–55 岁，注册即可声明"不面向未成年人"，降低风险。

### 1.3 内容合规（社区生死线）
- 国内 UGC **不能只靠 AI 审核**：必须"**机器初审 + 人工复审**"双轨，且需有**违法违规内容处置机制**（举报、下架、留存日志）。
- MVP 内容量小，**以人工审核为主、AI 辅助**（AI 先筛广告/敏感词/疑似盗图，人工拍板）。
- 建立**敏感词库 + 先审后发**（尤其涉政、涉黄、诈骗、导流微信卖货）。钓鱼/登山垂类政治敏感度低，主要防：广告导流、虚假收费信息、盗图。
- 保留内容与操作日志（合规留存）。

### 1.4 交易/团购相关（第三阶段商业化才涉及，先知悉）
- 一旦做"严选服务/团购"，涉及**电商/广告法/消费者权益**，需商家资质审核、交易记录、售后机制。**MVP 完全不碰交易**，规避此类风险。

## 2. 线下活动安全与责任（原 PRD 提及但零风控 · 面向中老年风险极高）

> 45–55 岁人群户外活动（野钓/徒步）有**摔伤、心脑血管意外、溺水、走失**等真实风险。组织方责任重大，必须制度化。

### 2.1 MVP 阶段策略：**平台不自办高风险活动**
- MVP **不由平台主办**登山/野钓线下活动，避免主体责任。
- 若要做，仅做**低风险、近郊、成熟路线的小型体验**，且：

### 2.2 若开展活动的强制风控清单
- **免责与知情同意书**（书面/电子签），说明风险、参与者自负;
- **购买活动意外保险**（每场必买，成本计入）；
- **参与者健康自评**（有心脑血管/高血压等自行评估，平台不做医疗判断）；
- **专业领队 + 人数上限 + 安全预案**（集合点、紧急联系人、撤离方案）；
- **天气/路况熔断**：恶劣天气取消；
- **紧急联系人登记**。
- 平台定位为**信息撮合/组织协助**，而非"旅行社/户外俱乐部"（涉旅行社业务需资质）。

> 结论：线下活动放到**第三阶段商业化**，且先小规模、重风控、买保险、签免责，把它当"高风险功能"对待，不急上。

## 3. 技术架构与选型（对齐"1 人 + AI + 可外包"）

原则：**能买不自建、能托管不自运维、能简单不复杂**。目标是最快跑通 MVP，而非造完美系统。

### 3.1 推荐技术方案（轻量优先）

| 层 | 推荐 | 理由 |
|---|---|---|
| 客户端 | **微信小程序优先**（可选后续做 App） | 国内中老年触达门槛最低、无需下载安装、无需应用商店资质、微信登录天然、开发快；最适合 MVP 冷启动 |
| （备选）原生/跨端 | uni-app / Flutter | 若坚持独立 App，跨端省人力；但上架/推广成本高于小程序 |
| 后端 | **云开发 / Serverless**（微信云开发、或 云函数+云数据库） | 免运维、按量付费、1 人可维护；省去服务器/等保初期压力 |
| 数据库 | 云数据库（文档型起步）或 PostgreSQL | 第 2 阶段数据模型可直接落地；`attributes` JSON 天然适配文档库 |
| 存储/图片 | 对象存储(OSS/COS) + CDN | 实拍图多，需图片处理(压缩/水印/鉴黄) |
| 地图/定位 | 腾讯地图/高德 SDK | 钓点/线路定位 |
| AI 能力 | 大模型 API（内容规整/审核辅助/敏感词） | 不自建模型，调 API |
| 内容审核 | 云厂商内容安全 API + 人工后台 | 图文机审 + 人工复审 |

> **强烈建议：MVP 用微信小程序 + 云开发。** 对中老年触达、开发速度、合规门槛、你的资源规模都是最优解。独立 App 可作为验证成功后的第二步。

### 3.2 系统模块（逻辑）
```
[小程序端]
  ├ 情报流/详情/搜索
  ├ 结构化发帖 + 随手记
  ├ 同城群组(浏览)
  └ 个人中心/积分
        │ API
[云函数(业务逻辑)]
  ├ 帖子服务(发布/干货判定/trust_score 计算)
  ├ 互动服务(点赞/收藏/评论 + 去重限流)
  ├ 积分服务(结算/流水/风控规则)
  ├ 审核服务(机审 API + 人工队列)
  ├ AI 规整服务(调大模型 API)
  └ 埋点/统计
[云数据库] users/posts/interactions/points_ledger/reports...
[对象存储+CDN] 图片
[后台管理] 审核队列、内容管理、数据看板(可用低代码/简单 Web)
```

### 3.3 非功能要求（MVP 底线）
- 性能：信息流首屏 < 2s；图片懒加载/CDN。
- 安全：登录态、接口鉴权、防刷（限流/去重）、图片鉴黄。
- 可维护：日志、错误上报；数据可导出。
- 适老化：大字/高对比度、点击热区大、文案直白、少弹窗。

## 4. 内容审核与运营 SOP（MVP 可执行）

### 4.1 审核流程（先审后发）
```
用户提交 → 机审(敏感词/广告/疑似盗图/鉴黄) 
  ├ 明显违规 → 自动拒绝 + 提示修改
  └ 通过/存疑 → 人工队列 → 人工复审 
        ├ 通过 → 发布 + 干货判定 + 积分结算
        └ 拒绝 → 下架 + 理由 + 扣分(如属实违规)
```
- MVP 人工审核可由你 + AI 助手承担（量小），日清队列。
- 沉淀《审核标准手册》：什么算干货、什么算广告导流、盗图判定标准、避坑帖加标准。

### 4.2 冷启动运营节奏（对齐第一阶段冷启动策略）
| 周期 | 动作 | 目标 |
|---|---|---|
| 上线前 4–6 周 | 自建广州钓鱼/登山种子内容 | 100–150 条干货 |
| 上线前后 | 招募 10–20 位广州种子达人(钓具店/户外群主) | 供给自转启动 |
| 上线后 1–4 周 | 本地群组导流 + 1 场小型线下体验 | 首批真实用户 + 内容 |
| 持续 | 每周内容运营 + 数据复盘(看 KPI) | 达到冷启动门槛 |

### 4.3 达人激励（无现金、符合"无套路"）
创始达人专属徽章 + 首页推荐位 + 内容署名 + 后期活动优先权 + 段位加速。**用荣誉与曝光换持续供给**。

## 5. 盈利模式细化（温和合规 · 分阶段）

| 阶段 | 变现方式 | 说明 |
|---|---|---|
| MVP | **不变现** | 专注内容与留存，别过早商业化 |
| 第二阶段 | 轻会员（低价年费） | 去广告、高清攻略、无限收藏/离线、精准匹配 |
| 第三阶段 | 严选本地服务 / 精品线下小团 | 严格审商家、纯玩无购物；注意与"无套路"承诺的平衡与合规(见 1.4/2) |

红线：坚持**基础功能永久免费**（发帖/看攻略/同城），变现只做增值，绝不割韭菜、绝不信息流硬广。

## 6. 开发排期与里程碑（现实版 · 1 人 + AI + 可外包）

> 以微信小程序 + 云开发为前提。时间为"专注投入"估算，兼职则相应拉长。

### M0 · 立项准备（1–2 周，并行）
- 公司主体、ICP 备案启动；隐私政策/用户协议起草；确定小程序账号与开发资质。

### M1 · MVP 开发（约 6–10 周）
- 数据库建表(第 2 阶段模型) → 登录(微信+手机号) → 情报流/详情 → 结构化发帖 + 随手记 → 互动/举报 → 积分极简版 → trust_score 排序 → 审核后台 → 埋点。
- 并行：**种子内容自建**（不等开发完，先攒内容）。

### M2 · 内测闭环（约 4 周）
- 邀请制小范围内测（广州种子达人 + 首批用户）→ 收集数据 → 对照第一阶段 KPI 判定。
- 判定达标 → 进入第二阶段；未达标 → 修内容与留存，不加新功能。

### M3+ · 第二阶段（正式版）
- 结伴、兴趣社群、8 级双风格段位、达人认证、积分兑换、AI 反作弊、智能推荐。

### M4+ · 第三阶段（商业化）
- 轻会员、线下活动(重风控)、严选服务；扩城市、扩垂类(旅居/高尔夫/乡居)。

## 7. 风险登记册（Top 风险 + 应对）

| 风险 | 等级 | 应对 |
|---|---|---|
| 冷启动失败（没内容/没人） | 极高 | 种子内容先行 + 达人招募 + 单城单垂类聚焦（已定策略） |
| 合规/资质踩雷 | 高 | 公司主体 + 备案 + 邀请制内测 + 律师确认；MVP 不做交易/直播 |
| 线下活动安全事故 | 高 | MVP 不自办；开展则免责+保险+领队+熔断 |
| 内容审核跟不上 | 中 | 机审+人工双轨、量小可控、审核手册 |
| 资源不足/开发拖延 | 中 | 小程序+云开发降复杂度、范围严守 MVP、可外包 |
| 大厂抄袭 | 中 | 壁垒在"同龄人真实实测内容 + 本地深耕"，非功能本身；先建内容护城河 |
