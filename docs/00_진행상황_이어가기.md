> 마지막 업데이트: 2026-09-17 ｜ 다음 세션에서 이 문서부터 읽고 이어가면 됩니다.

## 1. 확정된 결정 (변경 시 여기 갱신)
- **제품명**: 知闲 (대외적으로 "退休生活" 병기 가능)
- **타깃**: 70后/80后, **45~55세** 반퇴·세컨드라이프 세대 (원 PRD의 "50~65세" 모순 수정함)
- **첫 도시**: 광저우(广州) / **첫 버티컬**: 낚시(钓鱼) + 등산徒步 2개
- **슬로건**: 退休不褪色，玩好后半生
- **형태**: **독립 앱** (위챗 미니앱 아님) — 장기 慢养, 단기 수익 안 나도 OK. 중국 사업자·ICP 있음
- **기술스택**: 프론트 **Expo (React Native) + TypeScript** / 백엔드 **NestJS + PostgreSQL + 객체스토리지** / **안드로이드 우선**(iOS는 Mac 준비되면) / 중국 境内 클라우드 호스팅
- **발제 정책**: 主입구 **강제 구조화 폼** + "随手记" 경량 입구(사진+한줄, 干货/적립 제외·강등) 병행
- **로그인**: 위챗 + 휴대폰번호 둘 다
- **구조화 필드 추가**: 낚시 `最近渔获`, 등산 `手机信号` + `救援/求助点`
